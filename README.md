# Polestar 奥卡兹监狱（部落）

《魔兽世界》Forever 的奥卡兹监狱进本前任务接取路线，部落角色 48 级可接。需要先安装 [Polestar Guides 0.3.7.2 或更新版本](https://www.curseforge.com/wow/addons/polestar)。

## 用 WowUp 安装

1. 在 WowUp 顶部选择 **WoW Forever**。
2. 打开 **获取插件 → 从 URL 安装**，粘贴本仓库地址 `https://github.com/ufolyx-niper/PolestarPack_AlcazPrison`。
3. 在 **我的插件** 中可为此插件开启自动更新。之后的正式版本通过同一仓库更新。
4. 在游戏里输入 `/polestar guides`，搜索「奥卡兹监狱」，打开「部落进本前接任务」。

手动安装请从 [Releases](https://github.com/ufolyx-niper/PolestarPack_AlcazPrison/releases/latest) 下载以 `-forever.zip` 结尾的安装包，解压到 Forever 的 `Interface/AddOns`。

[查看接取路线、NPC 坐标和资料来源](PolestarPack_AlcazPrison/README.md)。
